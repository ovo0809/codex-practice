# codex-practice

我的 Codex 学习和练习项目。

## 小蛇俱乐部：草地探险

一个无需安装依赖的中文 3D 第一人称贪吃蛇小游戏。你会从蛇头的视角在 24 × 24 的草地中自动前进，通过相对转向寻找红果子；右下角的小地图始终保持北方朝上，方便判断果子、边界和蛇身的位置。

游戏保留三种速度、本地最高分、暂停和重新开始，并支持键盘、触控按钮以及在 3D 画面上横向滑动。画面由浏览器原生 WebGL 绘制，不加载外部字体、图片、脚本或网络资源。

### 开始玩

使用支持 WebGL 的现代浏览器直接打开 `index.html` 即可。也可以使用 Node.js 18 或更新版本启动本地静态服务器：

```sh
npm start
```

然后打开 `http://localhost:3000`。如需更改端口，可以设置 `PORT` 环境变量后再运行启动命令。

### 操作

- 小蛇会自动向前移动。
- `←` 或 `A` 相对当前朝向向左转；`→` 或 `D` 向右转。
- `空格` 暂停或继续，`Esc` 暂停，结束后按 `Enter` 再来一局。
- 切换窗口或隐藏页面时自动暂停，返回后手动继续。
- 手机上可以轻触左右转向按钮，或在 3D 画面上水平滑动。
- 每颗红果子增加 10 分；碰到围墙或自己的身体时，本局结束。
- 开始前可以选择悠闲、标准或挑战速度；开始后本局速度锁定。
- 每吃 5 颗果子稍微提速，最快保持每格 120 毫秒。
- “柔和镜头”开启后，镜头会按格立即对齐并停止果子的浮动效果；初始状态会参考系统的减少动态效果偏好。
- 最高分保存在当前浏览器；浏览器禁止本地存储时仍可游玩，但刷新后不会保留分数。

### 验证

```sh
npm test
```

测试使用 Node.js 自带的测试工具，覆盖游戏规则、相对转向、暂停与重开、存储不可用以及 3D 渲染失败和恢复时的控制器行为。

### 文件说明

- `game-core.js`：移动、碰撞、食物、计分和速度等游戏规则。
- `renderer.js`：无依赖的 WebGL 3D 场景渲染。
- `game.js`：第一人称镜头、输入、小地图和界面状态。
- `index.html`、`styles.css`：响应式游戏界面。
- `scripts/serve.mjs`：无依赖静态服务器。
- `tests/game.test.cjs`：游戏规则测试。
- `tests/controller.test.cjs`：镜头和交互状态的回归测试。
