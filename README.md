# codex-practice

我的 Codex 学习和练习项目。

## 小蛇俱乐部

一个中文贪吃蛇小游戏：三个速度档位、本地最高分、暂停与重开，支持键盘、手机方向按钮和棋盘滑动。无需安装依赖，无外部字体、图片或网络请求。

### 开始玩

直接用现代浏览器打开 `index.html` 即可。也可以使用 Node.js 18 或更新版本启动本地服务器：

```sh
cd /workspace/codex-practice
npm start
```

在运行服务器的电脑上打开 `http://localhost:3000`。可用 `PORT=8080 npm start` 更改端口。

### 操作

- 方向键或 W / A / S / D 控制方向，准备界面按方向键即可开始。
- 空格暂停或继续，Esc 暂停，结束后 Enter 再来一局。
- 手机上使用方向按钮，或在棋盘上滑动。切换到其他窗口时自动暂停。
- 吃一颗红果子得 10 分，碰墙或碰到自己结束。每吃 5 颗果子稍微提速。
- 游戏开始前选择悠闲、标准或挑战速度，当前一局中速度选择锁定。
- 最高分保存在当前浏览器中；浏览器禁止存储时仍然可以玩，但刷新后不保留分数。

### 验证

```sh
npm test
```

使用 Node.js 自带的测试工具，覆盖移动、吃食物、转向队列、墙与自身碰撞、尾格移动、暂停、胜利和速度规则。

文件说明：`game-core.js` 为独立游戏规则；`game.js` 负责绘制、输入和界面；`styles.css` 负责自适应布局；`scripts/serve.mjs` 为无依赖静态服务器。
